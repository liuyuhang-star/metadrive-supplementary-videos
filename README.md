# MetaDrive supplementary videos

Six selected qualitative comparisons at traffic density 0.3. The videos compare SAC, SAC-Lag, CPO and Ours in five roundabout cases and one intersection case, using matching initial map and vehicle geometry. Playback is 5x.

Open `index.html` through the published website. Per-case seeds, outcomes and provenance notes are available in `data/`. These selected cases do not estimate aggregate performance. Cases 02 and 06 include different training seeds across policies. Original numerical replay limitations remain disclosed in the page and case data.

## GitHub Pages

Publish this directory as the root of a public GitHub repository. In Settings > Pages, choose Deploy from a branch, then the main branch and / (root). The .nojekyll file keeps this static site from being processed as Jekyll content.

https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

No models, private credentials, local filesystem paths or raw training records are included.
